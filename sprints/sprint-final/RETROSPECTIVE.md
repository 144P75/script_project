### Whoops! (ปัญหาที่พบและการแก้ไข)
- **เรียก AI ใน lock ทำให้ request อื่นรอ** API อาจใช้เวลานานถึง 10 วินาที
  → อัปเดตสถานะและบันทึกใน lock แล้วเรียก AI นอก lock
- **Gemini ฟรีตอบ 503 / 429 เป็นพักๆ** ผู้ใช้เห็นออฟไลน์ทั้งที่ key ใช้ได้
  → ลองใหม่ 1 ครั้งก่อนตกไปออฟไลน์ เปลี่ยนรุ่นเริ่มต้นเป็น lite และพิมพ์สาเหตุลง log ให้ดีบักได้
- **AI พูดตัวเลขสถานะไม่ตรงกับหน้าจอ** เพราะสถานะเปลี่ยนตามเวลาหลังส่งข้อความ
  → สั่งใน prompt ให้บอกเป็นความรู้สึกแทนตัวเลข
- **CI ล้มเพราะไฟล์ไม่มีบรรทัดว่างท้ายไฟล์** ทั้งที่เทสต์ผ่านหมด
  → แก้ไฟล์ และตั้ง VS Code ให้เติมบรรทัดว่างอัตโนมัติ — CI ทำหน้าที่กันโค้ดผิดมาตรฐานเข้า main ได้จริง
- **deploy แล้วทุกคนเห็นสัตว์เลี้ยงชุดเดียวกัน** ระบบเดิมออกแบบสำหรับผู้เล่นคนเดียว
  → แยกข้อมูลตามรหัสผู้เล่นของเบราว์เซอร์ และตรวจรูปแบบรหัสกันการอ่านไฟล์นอกโฟลเดอร์
- **gunicorn หลาย worker จะทำให้บั๊กข้อมูลหายจาก Sprint 3 กลับมา** เพราะ lock ใช้ได้ใน process เดียว
  → กำหนด 1 worker หลาย thread ใน `render.yaml`
- **Gemini รุ่น lite บางครั้งปนอักษรลาว** ยังไม่ได้แก้ในโค้ด บันทึกเป็น known issue
