### Whoops! (ปัญหาที่พบและการแก้ไข)
- **`main.py` มี if/elif ยาว และทุกคำสั่งเรียก history + save เอง** ถ้าเขียนเว็บแยก ตรรกะเดียวกันจะมีสองที่
  → Refactor เป็น `PetService` ให้ทั้งสองฝั่งเรียกร่วมกัน
- **ลบพร้อมกันบนเว็บแล้วข้อมูลหาย** Flask รับหลาย request พร้อมกัน แต่ละ request โหลดไฟล์เดิมแล้วเขียนทับกัน
  → ใส่ `threading.RLock` ใน `PetService`
  ข้อจำกัด: lock ใช้ได้ในโปรเซสเดียว ถ้า CLI กับเว็บเขียนในเสี้ยววินาทีเดียวกันยังมีโอกาสทับกัน ทางแก้ในอนาคตคือ file lock หรือ SQLite
- **error บางกรณีตอบเป็นหน้า HTML** เช่น path ที่ไม่มี ทำให้หน้าเว็บอ่านไม่ได้
  → เพิ่ม error handler ให้ตอบ JSON ทุกกรณี
- **ปุ่มเปลี่ยนชื่อ/ลบบนเว็บไม่ทำงานในบางเบราว์เซอร์** เพราะใช้กล่อง `prompt()`/`confirm()` ซึ่งถูกบล็อกได้
  → แก้ชื่อในแถวโดยตรง และให้กดยืนยันการลบบนปุ่มเอง ไม่พึ่งกล่องของเบราว์เซอร์
