# Retrospective — Sprint 2

### Wow! (สิ่งที่ทำได้ดี)
- โหลดข้อมูลสัตว์เลี้ยงจากไฟล์ได้จริง และจำตัวที่เลี้ยงล่าสุด ผู้ใช้เล่นต่อจากเดิมได้ทันที
- Business Logic แจ้งข้อผิดพลาดด้วย Custom Exceptions ทำให้ UI จัดการได้เป็นระบบ และพร้อมให้เว็บแปลงเป็น HTTP status ใน Sprint 3
- `JsonStore` รับมือได้ทั้งไฟล์หาย ไฟล์เสีย และข้อมูลเสียบางส่วน โดยเก็บไฟล์ที่เสียไว้ให้ตรวจสอบ
- ค้นหา/กรอง/เรียงลำดับทำได้หลายคุณลักษณะ ข้อมูล 1,000 รายการใช้เวลาประมาณ 1 ms
- เทสต์เพิ่มจาก 8 เป็น 39 เทสต์ และไม่เรียกอินเทอร์เน็ตจริง

### Whoops! (ปัญหาที่พบและการแก้ไข)
- **ระบบเซฟซ้อนกัน 2 ระบบ** (`pet_state.json` กับ `pets.json`) → รวมให้เหลือ `PetManager`
- **ไฟล์ backup ไม่ช่วยอะไร** เดิมเขียนพร้อมไฟล์หลักจึงเหมือนกันเสมอ → backup เก็บเวอร์ชันก่อนหน้า และเขียนไฟล์หลักแบบ atomic
- **decay ไม่ทำงานเมื่อกดคำสั่งถี่** เพราะปัดเศษวินาทีทิ้ง → เลื่อน `last_updated` ตามหน่วยที่ใช้จริง
- **`web/history.py` อยู่ผิด Layer** → ย้ายไป `src/history.py`
- **เทสต์ชื่อไม่ตรงกับโค้ด ทำให้ CI ไม่ผ่าน** → แก้ชื่อ และแยกไฟล์เทสต์ตามคลาส
