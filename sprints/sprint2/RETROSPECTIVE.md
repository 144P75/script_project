# Retrospective — Sprint 2
### Wow! (สิ่งที่ทำได้ดี)
- โปรแกรมสามารถโหลดข้อมูลสัตว์เลี้ยงจากไฟล์ JSON ได้จริง และแสดงข้อความต้อนรับผู้ใช้เมื่อเริ่มใช้งาน ทำให้ผู้ใช้มั่นใจว่าสถานะถูกบันทึกไว้  
- ระบบตรวจสอบชื่อสัตว์เลี้ยงเมื่อใช้ `switchpet` และแจ้งเตือนหากไม่พบ รองรับ Multi-Pet Management ได้ครบตามที่ออกแบบ  
- ทุก Interaction (`feed`, `play`, `sleep`, `fact`) ถูกบันทึกลง Interaction History และสามารถค้นหา/กรอง/เรียงลำดับได้ มีข้อมูลย้อนหลังสำหรับการทดสอบและใช้งานจริง  
- โปรแกรมทำงานต่อเนื่องใน loop โดยไม่ crash มีความเสถียรและพร้อมใช้งานจริง  

### Whoops! (สิ่งที่ยังต้องปรับปรุง)
- ระบบยังไม่มีการแสดงผลแบบกราฟิกหรือ UI ที่เป็นมิตรต่อผู้ใช้ทั่วไป CLI เป็นข้อความล้วน อาจทำให้ผู้ใช้ใหม่สับสน  
- Interaction History ยังไม่ถูกแสดงผลในรูปแบบตารางภายใน CLI ต้องปรับปรุงให้ผู้ใช้เห็นข้อมูลย้อนหลังได้ชัดเจนขึ้น  
- Unit Test ยังไม่ครอบคลุม edge cases เช่น การป้อน input ที่ผิดรูปแบบหลายครั้งติดกัน หรือการจัดการไฟล์ JSON ที่เสียหายบางส่วน ต้องเพิ่ม test case เพื่อความมั่นใจในความเสถียร
